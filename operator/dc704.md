# Prompt Injection in Practice: Hands-On with The Warden

**Presenter:** Brian Chastain (off.by.1)  
**Category:** AI Security / Hands-On Lab  
**Duration:** 120 min 

## Abstract

30-minute talk on prompt injection: what it is, why it remains the
most reliable LLM attack years after being named, why "the model
was told not to" isn't a defense, and how the technique families
(direct, indirect, context shift, encoded, multi-turn,
retrieval-poisoned) map to OWASP LLM01.

90-minute lab on The Warden (warden.scalingsuccess.io): an 8-level
prompt-injection CTF extending Lakera Gandalf with a production-style
stack — input moderation → layered system prompt → output guard,
pluggable across OpenAI/Anthropic/xAI, with live Slack alerts so the
room watches defenses fire in real time. Each level adds one rule,
pushing attendees from direct asks and base64 into context shifts,
persona breaks, translations, and semantic-only leaks; the final
level is intentionally hard. Participants leave having cracked
multiple hardened prompts and with a working model of how production
guardrails fail.
